# AGENTS.md

Skip (skip.dev) dual-platform app: one SwiftUI codebase in `Sources/TanukiApp/` runs on iOS and Android. The app module is a Skip Fuse **native** module (Swift compiled for Android via the Swift Android SDK; `Sources/TanukiApp/Skip/skip.yml`), while SkipUI itself is transpiled. GitLab's GraphQL API is accessed through the checked-in Apollo-generated package at `GitLabAPI/`.

## Layout

- `Sources/TanukiApp/` — shared app module. In Fuse mode, Swift APIs used from Kotlin must be annotated `/* SKIP @bridge */` (see `TanukiAppRootView`); auto-bridging is not enabled. Kotlin/Gradle settings for this module go in `Sources/TanukiApp/Skip/skip.yml`.
- `Darwin/` — Xcode app shell. `Darwin/Sources/Main.swift` is the `@main` entrypoint; open `Project.xcworkspace` and run the `TanukiApp App` scheme.
- `Android/` — Gradle project generated by the skipstone plugin. `Android/app/src/main/kotlin/Main.kt` is the hand-maintained Android entrypoint and must stay in sync with `AndroidManifest.xml`; other Kotlin under `Android/` is generated (never edit build output).
- `GitLabAPI/` — path dependency of the root package containing Apollo-generated GitLab code. Hand-edit only `GitLabAPI/Sources/Schema/SchemaConfiguration.swift`.
- `Skip.env` — single source of app metadata for both platforms (PRODUCT_NAME must equal the Swift module name, bundle id/app id, versions). Change it here, not in `Info.plist` or `AndroidManifest.xml`.

## Build and run

- Running the Xcode scheme also builds and launches Android via `skip gradle` — controlled by `SKIP_ACTION` in `Darwin/TanukiApp.xcconfig` (currently `launch`). Set `SKIP_ACTION = none` for iOS-only work so no Android emulator is needed.
- CLI equivalents: `skip app launch` (build/run both platforms), `skip devices` (list emulators), `skip doctor` (toolchain diagnosis).
- `swift build` and `swift test` run the package natively on macOS from the repo root.
- There are no test targets yet; `swift test` and `skip test` currently run nothing despite what `README.md` says.

## Apollo GraphQL

- Operations live in `Sources/TanukiApp/Queries/*.graphql`; generated types are public API of the `GitLabAPI` module (`import GitLabAPI`, e.g. `CurrentUserQuery`).
- After changing an operation, regenerate from the repo root: `./apollo-ios-cli generate` (reads `apollo-codegen-config.json`). Add `-f` or run `./apollo-ios-cli fetch-schema` to re-download the schema from `https://gitlab.com/api/graphql` first (network required).
- `apollo-ios-cli` v2.4.0 is checked in at the repo root — use it. Generated sources under `GitLabAPI/Sources/{Schema,Operations}` are checked in and marked `@generated`, so don't hand-edit them.
- `gitlab@current.graphqls` is the ~2.5 MB GitLab SDL: grep it, never read it whole.
- `GitLabAPI/Package.swift` pins apollo-ios `exact: 2.4.0`; the root package requires `from: 2.4.0`. Bump both together.
